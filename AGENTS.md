# Public agent plugins

This repository contains reusable, public workflows. Keep instructions independent
of a particular agent application where possible. Retain packaging adapters and
host-specific details when they are necessary for actual installation or use.

- Keep personal writing preferences, project records, account identifiers,
  credentials, and real local paths out of repository content and examples.
- Use placeholders for project-specific configuration. Preserve third-party
  attribution and license notices.
- Plugin author metadata uses the public account name without a personal email.
  Use the repository's GitHub noreply identity for new commits.
- Read the affected skill and its references before changing instructions.
  Preserve current user authorization and existing project data.
- When changing the plugin list, update the marketplace and relevant READMEs,
  and remove dangling references. Check manifests and referenced local files.
- Review the diff, stage only the intended changes, and verify the push result.
  Do not rewrite published history without explicit authorization.
